# License overview and third-party terms

This is a licensing inventory for an unofficial Create compatibility project, not a new license grant over upstream work. Public redistribution of the private full-asset runtime jar has not been cleared.

## Create code and assets

The pinned official Create 6.0.10 license applies MIT terms to files outside its specified reserved-assets directory and reserves rights to files under src/main/resources/assets/. Preserve and read the complete upstream text in [Create-6.0.10-LICENSE.md](licenses/Create-6.0.10-LICENSE.md).

The Fabric donor has its own matching split-license notice in [Create-Fabric-donor-LICENSE.md](licenses/Create-Fabric-donor-LICENSE.md). These notices must not be replaced with a blanket MIT or All Rights Reserved label for all included components.

The audited private jar includes reserved-source assets. This document does not authorize their redistribution. Permission or a separately validated distribution that does not redistribute those assets is still required to establish an appropriate release route.

## Other components

Libraries retain their respective licenses, including MIT, LGPL-3.0-or-later, MPL-2.0, and embedded component-specific notices. See [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) and the verbatim documents in licenses/.

Some required notices and exact matching source obligations remain unverified. Copies of standard license texts do not, by themselves, establish complete compliance. No third-party code or assets are relicensed by this overview.

## Fork contributions and documentation

The final license choice and copyright attribution for eligible original fork contributions remain pending maintainer confirmation. Existing third-party copyright notices remain applicable. This overview grants no additional rights to those materials and must not be described as final public-release licensing clearance.
